# DemoApp — супровід програм

ПР-57. Автор: Котяш Федір.

Консольний застосунок для привітання користувача. dev — поточна розробка; master — перевірені випуски; release/1.1 — підготовка версії 1.1.

## Запуск
Потрібен .NET SDK 10.0.
```sh
dotnet run --project DemoApp
```

Версія 1.0 запитує ім’я та виводить привітання. Версія 1.1 додатково запитує вік, виводить ім’я, вік і статус повноліття.
